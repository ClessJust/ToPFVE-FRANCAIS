# ToPFVE-FRANCAIS
Tales of Phantasia Full voice edition en Français

ToPFVE-FRANCAIS
____________________________________________________

Sortie initiale : 25/09/2026

____________________________________________________

Basé sur la traduction française de Tales of Phantasia X Edition et du patch anglais de Life Bottle Production. Outils créés par mziab

___________________________________________________

Tales of Phantasia Full Voice Edition est disponible en français !

 Le jeu est entièrement traduit, et réutilise en grande majorité notre travail effectué sur ToP X Edition.
 Certains sprites textuels ont été modifiés pour rendre le tout plus lisible.

Version 1.0 : 

- Texte entièrement traduit en français

- Assets graphiques textuels entièrement remaniés

- Ajustements diacritiques

- Améliorations du gameplay par Life Bottle Production, incluant, sans s'y limiter :

- Fioles sacrées améliorées (évite rencontre ennemi au lieu de réduire fréquence)

- Certains objets supplémentaires peuvent être conservés dans une nouvelle partie +
    
- Sous-titrage saynètes

- Ajout d'une icône pour saynètes lorsqu'une nouvelle est disponible

- Crédits de fin modifiés pour inclure notre équipe

- Correction de l'affichage des faiblesses d'Ishrantu dans le Bestiaire

Cette traduction a été réalisée dans le but d'offrir une traduction fidèle à la version originale japonaise, 
en s'appuyant sur toutes les ressources possibles. Il est à noter que si la plupart des termes techniques utilisés sont les termes officiels, 
implémentés dans la série par l'équipe de traduction de Bamco, notre version apporte quelques changements, 
par souci de fidélité à l'oeuvre originale, ou par limitations techniques.
